DNS

Domain Name System

What it is: Translates domain names (like google.com) into IP addresses that computers understand.
Why it matters: Without DNS, you'd have to remember numeric IP addresses for every website.
Real-world use: Every time you type a URL, DNS resolves it to the correct server.

Caching

Speed Through Storage

What it is: Storing copies of data so future requests are served faster.
Why it matters: Reduces load on servers and dramatically improves response times.
Real-world use: Browser cache, CDN caching, AWS CloudFront.

APIs

Application Programming Interfaces

What it is: A way for different applications to talk to each other and share data.
Why it matters: Powers every modern app — from weather apps to payment gateways.
Real-world use: Stripe payment API, Google Maps API, Twitter API.

AWS EC2

Elastic Compute Cloud

What it is: Virtual servers (instances) in AWS that you can launch and configure in minutes.
Why it matters: Eliminates the need to buy physical servers — rent compute on demand.
Real-world use: Hosting web applications, running backend servers, deploying APIs.

SSH

Secure Shell Protocol

What it is: A secure protocol to remotely connect and control a server via the command line.
Why it matters: Standard way developers and cloud engineers access remote servers.
Real-world use: Connecting to AWS EC2 Linux instances from your laptop.

RDP

Remote Desktop Protocol

What it is: Microsoft's protocol to remotely access a Windows machine with a graphical interface.
Why it matters: Makes managing Windows servers easy and visual.
Real-world use: Accessing AWS EC2 Windows instances with a full desktop UI.

Virtualization

One Machine, Many Servers

What it is: Technology that creates multiple virtual machines on a single physical server.
Why it matters: The foundation of cloud computing — enables EC2 instances to exist.
Real-world use: AWS uses virtualization to run thousands of EC2 instances on their data center hardware.

Website Hosting

Putting Your Site on the Internet

What it is: Making your website files accessible on the internet via a server or cloud storage.
Why it matters: Every website you visit is hosted somewhere — this is how it gets there.
Real-world use: AWS S3 for static sites, EC2 for dynamic web apps.
